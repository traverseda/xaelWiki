# Outlining / structure notes

A structure note (a map of contents) exists to make a cluster of notes
findable as a group. It is an index with judgment, not a summary.

Write one when:

- Five or more notes orbit the same idea and there is no obvious single entry
  point.
- A search for the topic returns several results and no note explains how
  they relate.

Keep it thin: a one-paragraph why, then a linked list of the notes in order
of usefulness. The links are the content; the prose is the glue. If a
structure note would be longer than the notes it links, you have built a
duplicate, not a map.
