# Capture guidance

Capturing is the one step you should do quickly. You are recording something
the wiki does not already contain, so that it exists later — not producing a
finished document.

- Capture when an idea, fact, decision, or reference is worth keeping and a
  search does not already find it.
- Title with a noun-phrase subject, not a sentence: "Postgres row-level
  locking", not "I learned about postgres locks today".
- If the content extends an existing note, append to that note instead of
  capturing a new one. Search first.
- Use one or two tags that already exist. Rough is fine at capture time; the
  organizer cleans up.
- Add `links` to related notes when you know them offhand. Links made while
  the context is fresh are the most valuable links.
- Set `source` when the content came from a specific place — a URL, a
  conversation, a codebase.
